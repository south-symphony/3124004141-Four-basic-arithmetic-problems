# 小学四则运算题目生成器

> 
> 基于 Java Swing 开发的小学四则运算题目生成与批改工具，支持图形界面与命令行双模式。

## 项目简介

本项目实现了一个面向小学数学习题场景的四则运算题目生成器，支持自然数、真分数、带分数的加减乘除混合运算。程序严格遵循运算约束：单题运算符不超过 3 个、减法无负数、除法结果为真分数，并基于加法与乘法交换律实现题目自动去重。同时提供作业自动批改功能，可快速统计作业对错情况。

## ✨ 功能特性

- **双模式运行**：提供 Swing 图形化操作界面，无需记忆参数；同时兼容命令行模式，支持脚本批量调用
- **精确分数运算**：自定义分数运算类，全程整数运算实现，无浮点精度损失
- **严格题目约束**：单题运算符数量 ≤ 3、减法运算结果非负、除法结果为真分数
- **自动去重机制**：基于表达式树规范化的等价题目判定，交换律等价题目自动去重
- **作业自动批改**：读取题目文件与答案文件，自动计算并统计对错题号
- **内置文件预览**：图形界面支持直接预览题目、答案与批改结果

## 📦 运行环境

- JDK 1.8 及以上版本
- 全平台兼容：Windows /macOS/ Linux

## 🚀 使用方法

### 方式一：图形界面模式（推荐）

1. 双击 `ArithmeticGenerator.jar` 启动程序，或执行命令：
```
java -jar ArithmeticGenerator.jar
```
2. **生成题目**：左侧面板输入题目数量与数值范围，点击「生成题目」即可
3. **批改作业**：右侧面板选择题目文件与答案文件，点击「开始批改」即可
4. 点击对应按钮可直接在界面内预览生成的文件内容

### 方式二：命令行模式

#### 生成题目

```
java -jar ArithmeticGenerator.jar -n 题目数量 -r 数值范围
```

- `-n`：生成题目的数量，默认值为 10
- `-r`：题目中数值的取值范围，必填参数

示例：生成 100 道数值范围在 20 以内的题目

```
java -jar ArithmeticGenerator.jar -n 100 -r 20
```

#### 批改作业

```
java -jar ArithmeticGenerator.jar -e 题目文件路径 -a 答案文件路径
```

- `-e`：待批改的题目文件路径
- `-a`：学生答案文件路径

示例：批改当前目录下的作业

```
java -jar ArithmeticGenerator.jar -e Exercises.txt -a Answers.txt
```

## 📄 输出文件格式

### Exercises.txt（题目文件）

每行对应一道题目，自带题号，示例：

```
1、7 × 2/3 =
2、5 - 2'1/4 =
3、1/2 + 1/3 × 4 =
```

### Answers.txt（答案文件）

每行对应一道题的标准答案，自动约分为最简形式，大于 1 的分数以带分数表示：

```
1、4'2/3
2、2'3/4
3、2'1/6
```

### Grade.txt（批改结果文件）

统计正确与错误的题数及对应题号：

```
Correct: 3 (1, 3, 5)
Wrong: 2 (2, 4)
```

## 📁 项目结构

```
src/main/
├── AppMain.java             # 程序入口，命令行/图形模式分发
├── MainFrame.java           # Swing 图形化主界面
├── ProblemGenerator.java    # 批量题目生成与去重
├── ExpressionGenerator.java # 表达式递归生成与括号处理
├── AnswerGrader.java        # 作业批改与表达式解析
└── Fraction.java            # 精确分数四则运算类
```
